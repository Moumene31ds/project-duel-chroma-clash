## 🎮 Highlights & Features

- **20 Legendary 1v1 Minigames**:
  - ⚔️ **Neon Blade Duel**: Reaction-timing cyber quickdraw with ms-precision and false-start fouls.
  - 💣 **Cyber Bomb Relay**: Escalating plasma bomb deflection with physics-based Super Smashes.
  - 🏒 **Cyber Hockey**: High-octane neon air hockey with continuous collision detection (CCD).
  - 🥋 **Physics Sumo**: Momentum-based physics ring-out arena.
  - 🚀 **Laser Drift Racers**: Mode-7 pseudo-3D drift racing across space hyperways.
  - 🪐 **Neon Orbit Breaker**: Orbital mechanics and black hole gravitational slingshot duel.
  - 🥊 **Counter Dash**: Street-fighter style parry and dash combat.
  - 🛡️ **Tactical Tanks**: Ricochet ballistics and destructible obstacles.
  - 🏀 **Cyber Hoops**: Arc trajectory basketball with combo swish streaks and ON FIRE status.
  - 🔮 **Laser Pinball**: Dual flipper neon pinball with fusion multiballs.
  - 🏐 **Neon Volley**: 2D cyber beach volleyball with spike physics.
  - ⚓ **Quantum Tug**: Reverse tug-of-war button smasher.
  - 🛸 **Astro Blast**: Retro space dogfight duel with energy shields.
  - 🥷 **Cyber Slicer**: Fast-paced geometry slicing and reflex cutting.
  - 🎵 **Synthwave Rhythm**: 80s synthwave falling note rhythm game.
  - 🏃 **Gravity Runner**: Dual endless runner with inverted gravity flips.
  - 🧠 **Chroma Pairs**: High-speed memory card matrix.
  - 🧩 **Memory Matrix**: Simon-says path recall test.
  - 🔴 **Cyber Simon**: Polar-coordinate color reflex challenge.
  - 👁️ **Chroma Reaction**: Stroop effect cognitive reflex battle.

- **🤖 Adaptive AI Bots**: 3 difficulty tiers (`Casual`, `Adaptive`, `Pro`) supporting all 20 minigames in solo mode.
- **👑 Party Board Mode**: Mario-Party style board game with dice rolls, shop tiles, coins, stars, and minigame duels.
- **🏆 Cyber Tournament Bracket**: Single elimination and Best-of-3 cups with dynamic brackets.
- **💀 Gauntlet Boss Rush**: 5-stage escalating boss gauntlet with life management and instant revive.
- **🎲 Game Mutators**: Sudden Death, Turbo Speed, Invert Gravity, Mirror Mode, and Hyper Fever.
- **📺 Cyber Ad System**: Built-in rewarded ads (Free Daily Gifts, 2x Victory Double Rewards, Gauntlet Revive) and smart interstitials with frequency capping.
- **📱 Ultra-Responsive Mobile Design**: Full portrait layout, `100dvh` viewport adaptation, safe-area insets (`env(safe-area-inset)`), touch-optimized controls (48px+ targets).
- **🔊 Procedural Web Audio & Haptics**: 100% synthesized sound effects, dynamic music layers, and vibration feedback without external sound files.
- **🌍 Bilingual Support**: Full Arabic (RTL) and English (LTR) localization.

## 🚀 Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Installation & Development
```bash
# Clone the repository
git clone https://github.com/Moumene31ds/project-duel-chroma-clash.git
cd project-duel-chroma-clash

# Install dependencies
npm install

# Start development server
npm run dev
```

### Run Tests
```bash
# Run 54 comprehensive engine unit tests
npm test
```

### Production Build
```bash
# Build production bundle with TypeScript check & Vite
npm run build
```

## 🛠️ Tech Stack

- **Language**: TypeScript (Strict Mode)
- **Bundler**: Vite
- **Renderer**: Pure HTML5 2D Canvas (60–120 FPS render loop)
- **Audio**: Web Audio API (Procedural Synthesizers & Lowpass Filter)
- **PWA**: Web App Manifest & Service Worker offline support
- **Testing**: Node.js Test Runner & Assertions
